# Чат с ИИ-персонажами

Сайт: на главной поиск и карточки персонажей, по клику открывается чат. Ответы генерирует ИИ через любой OpenAI-совместимый API. Персонажи хранятся в базе данных SQLite, управлять ими можно через админку. Ключ от ИИ хранится на сервере и в браузер не попадает.

Внешних пакетов нет: `npm install` не нужен.

## Запуск

Нужен Node.js **22.13 или новее** (SQLite встроена в Node).

```bash
cp .env.example .env     # затем откройте .env и заполните настройки
npm start
```

Сайт откроется на http://localhost:3000, админка на http://localhost:3000/admin.html.

В `.env` нужно заполнить:

- `API_BASE_URL`, `API_KEY`, `MODEL`: адрес API провайдера, ваш ключ и название модели (примеры в `.env.example`). Бесплатные модели и лимиты у провайдеров меняются, актуальные названия смотрите в их документации. Сменить провайдера можно, поменяв только эти три строки.
- `ADMIN_PASSWORD`: пароль для входа в админку. Придумайте длинный (от 12 символов). Без него админка выключена.

После любого изменения `.env` перезапустите сервер.

## Админка

Откройте `/admin.html` и войдите по паролю. Там можно:

- создавать, править и удалять персонажей;
- загружать картинки прямо с компьютера (PNG, JPG или WebP до 3 МБ, лучше вертикальные 3:4, около 600×800);
- задавать жанры (они сами появляются кнопками на главной), эмодзи, приветствие и инструкцию для ИИ;
- временно скрывать персонажа с сайта, не удаляя его;
- менять порядок карточек на главной (поле «Порядок», чем меньше число, тем раньше).

Ссылки на админку на сайте нет, адрес знаете только вы. После 5 неверных паролей подряд вход блокируется на 15 минут.

## Русский и английский

В правом верхнем углу главной и в шапке чата есть переключатель **RU | EN**. Выбор запоминается в браузере. Если посетитель ещё ничего не выбирал, сайт откроется на английском в англоязычном браузере и на русском во всех остальных.

- **Интерфейс** (кнопки, подсказки, сообщения об ошибках) переводится автоматически. Тексты лежат в `public/i18n.js`.
- **Персонажи**: у каждого в админке есть блок «English version» (имя, подпись, жанры, приветствие). Если поле оставить пустым, на английском сайте покажется русский текст. Картинка и эмодзи общие для обоих языков.
- **Ответы ИИ**: модель получает подсказку отвечать на языке сайта, если собеседник не пишет на другом. Инструкцию для ИИ (характер) писать на одном языке достаточно.
- Если переключить язык посреди диалога, уже написанные сообщения остаются как были, а новые ответы пойдут на выбранном языке.
- Админка остаётся только на русском.

Чтобы добавить третий язык, нужно: дописать код в `SUPPORTED_LANGS` (`util.js`), добавить словарь в `public/i18n.js` и сообщения в `MESSAGES` (`server.js`). В базе менять ничего не нужно, но в админке добавится ещё один блок полей.

## Фото в чате

Если собеседник просит фото («пришли фото», «покажи селфи на пляже», «send me a photo with coffee»), персонаж отправляет одно из заранее загруженных фото и коротко подписывает его в образе.

**Как добавить фото.** В админке выберите персонажа и в блоке «Фото для чата» нажмите «Загрузить фото». Можно выбрать сразу несколько файлов (PNG, JPG или WebP до 3 МБ, до 20 фото на персонажа). Имя файла становится темой и ключевым словом: `пляж.jpg` даёт тему «пляж». Потом для каждого фото можно поправить тему, ключевые слова (лучше на русском и английском: `пляж, море, beach, sea`) и добавить описание. Описание помогает персонажу точно подписать фото.

**Как выбирается фото.** Сайт распознаёт просьбу в сообщении (на русском и английском) и ищет фото, у которого тема или ключевое слово встречается в тексте. Слова сравниваются по основе, поэтому «пляж» найдёт «на пляже», а «собака» найдёт «собаку». Если темы в просьбе нет или такого кадра нет, берётся любое ещё не показанное. Одно и то же фото в одном диалоге повторяется только когда показаны все.

**Если фото у персонажа нет,** он вежливо отвечает, что отправить не может.

**Платная функция.** Аккаунтов и оплаты пока нет, поэтому есть переключатель в `.env`:

- `PHOTOS_ACCESS=everyone` (по умолчанию): фото доступны всем;
- `PHOTOS_ACCESS=locked`: фото не отправляются, персонаж вежливо отказывает, а в чате появляется плашка «Отправка фото доступна по подписке».

Когда появятся аккаунты и оплата, проверку подписки нужно добавить в одном месте: функция `hasPhotoAccess` в `server.js` (и при желании в маршрут `/photos/` там же).

**Закрытость фото.** Файлы лежат в `data/photos/` под случайными именами, не входят в публичный список персонажей и не открываются через `/uploads/`. Адрес фото знает только тот, кому его отправили в чате.

**Облачная генерация позже.** Выбор фото собран в одном вызове (`pickPhoto` в `photos.js`, использование в `handleChat` в `server.js`). Чтобы подключить генерацию, замените этот вызов на запрос к генератору изображений: остальное (подпись, показ в чате, платный доступ) останется как есть.

## Где что хранится

Всё, что создаётся при работе, лежит в папке `data/` рядом с `server.js`:

- `data/app.db`: база данных (персонажи);
- `data/uploads/`: загруженные картинки персонажей (аватарки для карточек);
- `data/photos/`: фото для отправки в чате.

**Резервная копия** = копия папки `data/`. Другое место для неё можно задать переменной `DATA_DIR`.

Файл `characters.json` используется только один раз: при первом запуске, когда база пуста, персонажи переносятся из него в базу. Дальше правки в этом файле ни на что не влияют, всё делается через админку.

## Публикация в интернете

- Выберите хостинг, где папка `data/` **не стирается** при перезапуске: VPS или сервис с постоянным диском (volume). На бесплатных тарифах с временным диском база и картинки пропадут. В таком случае нужен постоянный диск или другая схема хранения.
- Если сайт стоит за прокси или на хостинге (Render, Railway, nginx), добавьте в `.env` строку `TRUST_PROXY=1`, чтобы лимиты считались по реальному IP посетителей.
- Включите HTTPS (его обычно даёт хостинг). Тогда cookie админки автоматически получит флаг `Secure`.

## Что внутри

- `server.js`: сервер, чат, раздача страниц; лимит 20 сообщений в минуту с одного IP;
- `db.js`: база данных и миграции. При обновлении проекта база обновляется сама, ваши данные сохраняются;
- `admin.js`: вход, управление персонажами, загрузка картинок и фото;
- `photos.js`: распознавание просьбы о фото и выбор фото по теме;
- `public/`: страницы (главная, чат, админка);
- история диалогов хранится в браузере посетителя, на сервере её нет.
